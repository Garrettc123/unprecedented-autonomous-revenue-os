# Evidence room

Tamper-evident hash chain. Not immutable.

A row is cash only when PaymentProjection records customer_cash from a signature-verified livemode Stripe event, last4 other than 4242, and the email is not the operator.

An outbound dial or send is refused unless ApprovalGate has a matching policy_decision_id. This file does not send the Jordan Gal or Tibo messages.

REDIS_URL, MARS_REASON_URL, and MARS_API_KEY are still host values. This module does not set them.

Perplexity threads are not linked here. No Perplexity connector wrote into this ledger.
